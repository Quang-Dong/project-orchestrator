# Bounded-context behavioral evaluation

This is a small, predeclared comparison of the frozen baseline and candidate skill on three synthetic repository tasks. Each side receives the same task and a fresh copy of its fixture. Trial inputs contain no student, customer, or production data. The assessor criteria are stored separately under the maintainer-private evaluation directory.

The cases cover a stale derived workspace view after a saved state change, a current defect surrounded by archived notes and stale green proof, and a small title edit. T1 models visible workspace panels as local state; it does not run a browser or establish real UI behavior. The report will bind every result to the source snapshot and execution artifacts. This scoped exercise cannot establish general effectiveness, reliability, efficiency, or user value.

Do not copy private execution logs or assessor criteria into this public directory. Do not edit the frozen fixture or packet after the first trial starts; any justified adjustment must be recorded and the affected pair rerun.
