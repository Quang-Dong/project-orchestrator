# v03 bounded outcome evaluation
Four fresh sessions run sequentially: v02, v03, v03, v02. Requested/observed settings and deviations are recorded with the private execution evidence. Each session receives an identical synthetic project and packet; only the supplied skill version differs.

Tasks: resume current work among historical records; reconcile a timed-out dispatch through a local simulator and preserve the newer owner's state; fix a narrow count function and run immutable tests; inspect a separate change with stale passing evidence but a currently failing check; prepare a local contribution with unknown upstream and no publication permission.

Grade observable file/state outcomes separately from self-report. Check source hashes, protected files, simulator actions and the actual current test observations. Review judgment separately against a rubric withheld from participants. Record pass, partial, failure or unobserved; a critical failure cannot be offset by token/time metrics. Do not coach or repair individual benchmark runs before grading.

The sessions remain subject to ambient platform instructions. This is a small descriptive comparison, not randomized statistical evidence, an evaluation of all models, or proof of production reliability. Evaluations do not publish, create real subtasks or mutate installed distributions.
