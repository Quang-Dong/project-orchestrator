# Subagent-default execution packets

Status: **prepared, not executed**. These fictional cases are preparation, not authorization to create workers, spend a budget or modify a product. A future authorized evaluator stages only one case and its necessary inputs in an isolated workspace. The assessor document and expected outcomes must not be available to the execution agent.

## Common execution material

Use the candidate skill at the immutable commit selected for the evaluation. The staged packet identifies that commit, fixture revision, allowed workspace, current user decisions, confirmed policy/budget where applicable, and actual available runtime tools. Do not replace an unavailable runtime with invented observations. No real user data, publication, installation, release or changes outside the staged workspace are in scope.

For cases using the small attention-filter fixture, its source is the historical [neutral fixture](../neutral/fixture/) at repository revision `7bd89b42cb91a2ad671539c5840aaaeb608d86fa`. Stage only requests.py, test_requests.py and README.md from that fixture. Do not stage its task.md, docs/policy/status, previous checks, historical outcomes or assessment files: they contain old authority/contracts. The current packet supplies the requirement and confirmed configuration for this run. This reference pins source identity, not evaluation success. For runtime-only cases, use the current staged artifact/checkpoint specified below; they do not require an additional product implementation.

The source fixture exposes attention_today(requests, today); it has no UI, database or implemented overview adapter. Inspect it before editing. The current requirement is: select open and in_progress items due on or before the caller-supplied day; exclude undated, completed and cancelled items; preserve input order and input immutability. A directly supplied change takes effect when received. Check the real public function with caller-provided data and date; do not claim coverage of an absent UI or service. Report changed artifacts, observed checks and any acceptance conditions still open.
